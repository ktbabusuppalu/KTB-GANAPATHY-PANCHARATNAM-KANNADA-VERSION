# ಗಣಪತಿ ಪಂಚರತ್ನಮ್ (Ganapati Pancharatnam - Kannada Version)

ಆದಿ ಶಂಕರಾಚಾರ್ಯರಿಂದ (8ನೇ শতಮಾನ) ರಚಿಸಲ್ಪಟ್ಟ ಪವಿತ್ರ ಗಣಪತಿ ಪಂಚರತ್ನಮ್. ಈ 5 ದಿವ್ಯ ರತ್ನಗಳು ಅಡೆತಡೆಗಳನ್ನು ನಿವಾರಿಸಿ ಜಜ್ಞಾನವನ್ನು ಕರುಣಿಸುತ್ತವೆ. ಆಡಿಯೋ ಮತ್ತು ಅರ್ಥದೊಂದಿಗೆ ಕನ್ನಡ, ತಮಿಳು ಹಾಗೂ ತೆಲುಗಿನಲ್ಲಿ ಡಿಜಿಟಲ್ ರೂಪದಲ್ಲಿ ಪ್ರಸ್ತುತಪಡಿಸಲಾಗಿದೆ.
